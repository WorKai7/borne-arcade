Borne Arcade - Comment jouer ?

Vue d'ensemble

Bienvenue sur votre borne d'arcade ! Cette borne vous donne accès à une collection de jeux contrôlables simplement avec un joystick et deux boutons. L'interface est conçue pour être intuitive et accessible à tous.

À savoir : La borne démarre automatiquement sur le menu principal. Aucune manipulation complexe n'est nécessaire pour commencer à jouer !

Important :
  • Le bouton GAUCHE (haut) sert uniquement à revenir en arrière
  • Le bouton DROIT (bas) sert à valider vos choix
  • Ne pas appuyer trop fort sur les boutons (ils sont robustes mais pas incassables !)

= Sélection actuelle

1

Choisir un jeu

Utilisez le joystick HAUT et BAS pour vous déplacer dans la liste des jeux. Le jeu sélectionné est mis en évidence.

2

Lancer le jeu

Une fois le jeu de votre choix sélectionné, appuyez sur le bouton DROIT (bas) pour lancer la partie.

3

Revenir au menu

Pendant une partie, appuyez sur le bouton GAUCHE (haut) pour revenir au menu principal.

Selon le jeu : Les contrôles peuvent légèrement varier. Un écran d'instructions est généralement affiché au début de chaque partie.
