Installation Borne Arcade

Guide complet pour Raspberry Pi 3 Model B

Prérequis matériels

🍓

Raspberry Pi 3 Model B

💾

Carte micro SD ≥16GB

⚡

Alimentation 5V/2.5A

🖥️

Écran HDMI

⌨️

Clavier et souris

🌐

Connexion internet

Installation de Raspberry Pi OS

1

Télécharger Raspberry Pi Imager

Téléchargez et installez Raspberry Pi Imager sur votre ordinateur

2

Insérer la carte SD

Insérez la carte micro SD dans votre ordinateur

3

Lancer Raspberry Pi Imager

Ouvrez l'application Raspberry Pi Imager

4

Configuration

  • Choisissez OS → Raspberry Pi OS (32-bit) Lite
  • Choisissez Storage → Sélectionnez votre carte SD
  • Configuration avancée (cliquez sur l'icône ⚙️ en bas à droite) :
    • Activer SSH
    • Définir nom d'utilisateur : pi
    • Définir mot de passe : (choisissez un mot de passe sécurisé)
    • Configurer WiFi
      • SSID : (nom de votre WiFi)
      • Mot de passe : (clé WiFi)
5

Écrire l'image

Cliquez sur ÉCRIRE et attendez la fin de l'écriture

Premier démarrage

# Insérez la carte SD dans le Raspberry Pi
# Branchez l'alimentation
# Attendez 1-2 minutes que le Pi démarre

# Depuis votre ordinateur, connectez-vous en SSH :
ssh pi@raspberrypi.local
# Mot de passe : celui défini dans l'imager

Mise à jour du système

sudo apt update && sudo apt upgrade -y
sudo apt install -y git

Clonage du projet

# Créer la structure de dossiers
mkdir -p ~/git
cd ~/git

# Cloner le projet
git clone https://github.com/WorKai7/borne-arcade.git
cd borne-arcade
Note : Le dépôt contient déjà les fichiers nécessaires :
  • lancerBorne.sh - Script de lancement du jeu
  • borne.desktop - Fichier de configuration pour l'autostart

Configuration du démarrage automatique

# Créer le dossier autostart s'il n'existe pas
mkdir -p ~/.config/autostart

# Copier le fichier desktop depuis le dépôt
cp ~/git/borne-arcade/borne.desktop ~/.config/autostart/
Le fichier borne.desktop contient : 
[Desktop Entry]
Type=Application
Name=Borne
Comment=
Exec=/usr/bin/lxterminal -e /home/pi/git/borne-arcade/lancerBorne.sh
Icon=gtk-dialog-authentication
NotShowIn=GNOME;KDE;
Hidden=false
Terminal=true
X-KeepTerminal=false

5️⃣ Test final et redémarrage

# Tester le lancement manuel
~/git/borne-arcade/lancerBorne.sh

# Si tout fonctionne, redémarrer
sudo reboot

🔍 Dépannage rapide

Le jeu ne se lance pas au démarrage

# Vérifier que le fichier desktop est bien placé
ls -la ~/.config/autostart/

# Vérifier les permissions
chmod +x ~/git/borne-arcade/lancerBorne.sh

# Vérifier les logs
cat ~/.xsession-errors

Problème de connexion SSH

# Sur le Pi directement (avec clavier/écran)
# Vérifier l'adresse IP
hostname -I

# Activer SSH si désactivé
sudo raspi-config
# → Interface Options → SSH → Enable

Erreur "Permission denied"

chmod +x ~/git/borne-arcade/lancerBorne.sh
chmod +x ~/.config/autostart/borne.desktop

Le terminal ne se lance pas

# Installer lxterminal si manquant
sudo apt install -y lxterminal

Résumé des commandes

# Installation complète en une ligne
sudo apt update && sudo apt upgrade -y
sudo apt install -y git
mkdir -p ~/git && cd ~/git
git clone https://github.com/WorKai7/borne-arcade.git
mkdir -p ~/.config/autostart
cp ~/git/borne-arcade/borne.desktop ~/.config/autostart/
sudo reboot

📁 Structure finale attendue

/home/pi/
├── git/
│   └── borne-arcade/
│       ├── lancerBorne.sh
│       ├── borne.desktop
│       └── ... (autres fichiers du jeu)
└── .config/
    └── autostart/
        └── borne.desktop (copie)

Notes importantes

🔧 Le script lancerBorne.sh

Assurez-vous que ce fichier est présent dans le dépôt et contient les commandes nécessaires pour lancer votre jeu.

Attention aux permissions

Les fichiers doivent être exécutables :

chmod +x ~/git/borne-arcade/lancerBorne.sh
Objectif final

À la fin de cette installation, votre Raspberry Pi :

  • Démarre automatiquement
  • Se connecte au WiFi
  • Lance le jeu sans intervention humaine
  • Est prêt à être utilisé comme borne d'arcade
