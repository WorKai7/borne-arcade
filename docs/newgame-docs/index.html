📦 Ajouter un jeu à la borne

Guide complet pour intégrer un nouveau jeu

🎯 Vue d'ensemble

L'ajout d'un jeu à la borne arcade se fait en 3 étapes simples :

📁

1. Copier le jeu

Drag & drop le dossier du jeu

🖼️

2. Ajouter les fichiers

Images, description, contrôles

🚀

3. Créer le lanceur

Script .sh pour démarrer

📁 Étape 1 : Structure des dossiers

1

Accéder au répertoire projet

Connectez-vous à la borne en SSH ou branchez un clavier/écran.

cd ~/git/borne-arcade/projet/
2

Créer le dossier du jeu

Créez un dossier avec le nom de votre jeu (sans espaces, tirets recommandés).

mkdir mon-nouveau-jeu
3

Drag & drop le code source

Copiez tous les fichiers du jeu dans ce dossier :

# Depuis votre ordinateur (en local)
scp -r /chemin/vers/mon-jeu/* pi@raspberrypi.local:~/git/borne-arcade/projet/mon-nouveau-jeu/

# Ou directement sur la borne
cp -r /media/usb/mon-jeu/* ~/git/borne-arcade/projet/mon-nouveau-jeu/
💡 Bonne pratique : Utilisez des noms de dossiers sans espaces, accents ou caractères spéciaux. Préférez les tirets : mon-jeu-arcade

🖼️ Étape 2 : Fichiers requis

Chaque jeu doit contenir ces 4 fichiers à la racine de son dossier :

📁 projet/
└── 📁 mon-nouveau-jeu/
    ├── 📄 photo.png         # Image de couverture (grande)
    ├── 📄 photo_small.png   # Image miniature
    ├── 📄 description.txt   # Description du jeu
    ├── 📄 boutons.txt       # Description des contrôles
    └── 📁 ...                # Code source du jeu

📷 photo.png

PNG - 800x600px recommandé

Image de couverture affichée dans le menu principal. Elle doit représenter le jeu (logo, screenshot, artwork).

📷 photo_small.png

PNG - 200x150px recommandé

Miniature affichée dans les listes ou aperçus. Version réduite de l'image principale.

📝 description.txt

TXT - UTF-8

Description du jeu qui s'affichera dans le menu d'information. Contenu :

Nom du jeu: Super Aventure
Genre: Plateforme
Année: 2024
Développeur: Game Studio
Joueurs: 1

Description: Un jeu de plateforme passionnant où vous incarnez un héros...

🎮 boutons.txt

TXT - UTF-8

Description des contrôles pour les joueurs. Exemple :

Joystick: Déplacements
Bouton DROIT: Sauter / Valider
Bouton GAUCHE: Retour au menu
⚠️ Important : Ces fichiers sont obligatoires. Sans eux, le jeu n'apparaîtra pas dans le menu de la borne !

🚀 Étape 3 : Créer le lanceur

1

Retour à la racine du projet

cd ~/git/borne-arcade/
2

Créer le fichier .sh

Créez un fichier avec le nom du jeu (ex: mon-nouveau-jeu.sh)

nano mon-nouveau-jeu.sh
3

Écrire le script selon le langage

🐍 Pour un jeu Python :

#!/bin/bash
cd ~/git/borne-arcade/projet/mon-nouveau-jeu
python3 main.py

☕ Pour un jeu Java :

#!/bin/bash
cd ~/git/borne-arcade/projet/mon-nouveau-jeu
javac *.java
java Main

❤️ Pour un jeu Love2D :

#!/bin/bash
cd ~/git/borne-arcade/projet/mon-nouveau-jeu
love .

🎮 Pour un exécutable :

#!/bin/bash
cd ~/git/borne-arcade/projet/mon-nouveau-jeu
./game
4

Rendre le script exécutable

chmod +x mon-nouveau-jeu.sh

✅ Vérification finale

Avant de tester, vérifiez que tout est en place :

📁 ~/git/borne-arcade/
├── 📁 projet/
│   └── 📁 mon-nouveau-jeu/
│       ├── 📄 photo.png
│       ├── 📄 photo_small.png
│       ├── 📄 description.txt
│       ├── 📄 boutons.txt
│       └── 📁 code source...
└── 📄 mon-nouveau-jeu.sh (exécutable)
# 1. Vérifier les permissions
ls -l ~/git/borne-arcade/*.sh

# 2. Tester le lancement manuel
~/git/borne-arcade/mon-nouveau-jeu.sh

# 3. Si tout fonctionne, redémarrer le menu
sudo reboot
✅ Votre jeu est prêt !

Il apparaîtra automatiquement dans le menu de la borne au prochain démarrage.

🔍 Dépannage

❔ Le jeu n'apparaît pas dans le menu

Vérifiez que les fichiers photo.png, photo_small.png, description.txt et boutons.txt sont bien présents dans le dossier du jeu.

❔ Le script ne se lance pas

Vérifiez les permissions : chmod +x mon-nouveau-jeu.sh

❔ Erreur "Fichier non trouvé"

Vérifiez le chemin dans le script .sh. Le chemin doit être absolu : /home/pi/git/borne-arcade/projet/...

❔ Le jeu se lance mais plante

Testez le jeu directement depuis le dossier pour voir les messages d'erreur : cd ~/git/borne-arcade/projet/mon-jeu/ && python3 mon-jeu.py

📝 Résumé des commandes

# 1. Aller dans le dossier projet
cd ~/git/borne-arcade/projet/

# 2. Créer le dossier du jeu
mkdir mon-nouveau-jeu

# 3. Copier les fichiers (drag & drop ou scp)
# ...

# 4. Créer les fichiers requis
cd mon-nouveau-jeu
nano photo.png        # (à transférer depuis votre PC)
nano photo_small.png  # (à transférer depuis votre PC)
nano description.txt  # Écrire la description
nano boutons.txt      # Écrire les contrôles

# 5. Retour à la racine et créer le lanceur
cd ~/git/borne-arcade/
nano mon-nouveau-jeu.sh

# 6. Rendre exécutable
chmod +x mon-nouveau-jeu.sh

# 7. Tester
./mon-nouveau-jeu.sh
💡 Astuce : Pour transférer facilement les images depuis votre PC, utilisez scp ou une clé USB. Les fichiers doivent être en format PNG.
